# Demo script (3-5 min shot list)

Prepare beforehand: 2-3 real clips (one clean daytime intersection, one night/rain, one crowded/occluded or
small-distant), a ground-truth CSV (`docs/ground_truth.md`), results generated by the `scripts/`.

| Time | Shot | Say / show |
|---|---|---|
| 0:00-0:20 | Title + one-line problem | Motorcycle detection, tracking, wrong-way and crosswalk-riding, decided over trajectories. |
| 0:20-0:50 | `docker compose up --build`, open :8080 | Offline, one command. Upload the clean clip with the progress bar. |
| 0:50-1:30 | Config canvas | Draw a crosswalk; draw a direction zone + arrow, tolerance slider; optional 4-point homography; save; Process with live progress/ETA/FPS. |
| 1:30-2:15 | Annotated playback (correct detections) | IDs, trailing trajectories, zone overlays, toggles, frame step. Click a true wrong-way event: seek + highlight; open evidence (entry/mid/exit/peak, reasons, metrics, merged raw IDs); Confirm. Show a true crosswalk event with rider state `riding`. |
| 2:15-2:45 | Correct *non*-detections + incorrect detections | A legal turn, a stopped bike on the crosswalk, and a walked bike not flagged. Then show one real false positive/false negative and a `Insufficient evidence` badge; Reject it. |
| 2:45-3:45 | **At least 3 challenging/failed cases** | (1) night/rain clip: missed detections, broken tracks. (2) heavy occlusion: ID switch / un-merged fragment. (3) small distant bikes: noisy heading, no event. Explain cause + mitigation (stitching, insufficient-evidence flag). |
| 3:45-4:30 | Metrics + speed | Show `docs/results.md`: precision/recall/F1, ID switches/fragmentation, FPS per stage CPU vs GPU. Report only the numbers the scripts produced. |
| 4:30-5:00 | Export + limits | JSON/CSV export with review status and evidence paths; known limitations; future work. |
